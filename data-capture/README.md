## Naming Convention

```
YYYY-MM-DD_location_subject_shot-number.ext
```

Example: `2026-06-10_simon_gilbert_quote_01.mov`

## Research Capture Protocol

1. Source material → web_search / web_extract / interviews
2. File into appropriate plane directory (regulatory, economic, etc.)
3. Format as YAML-frontmatter markdown where possible
4. Commit with descriptive message
5. Cross-link related findings
