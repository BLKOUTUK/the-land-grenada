# Geographical Plane

What is the land, climate, and ecology?

## Location

- Simon, St Andrew Parish, north-east Grenada
- Coastal, ~seven acres
- Proximity: Levera Beach (resort development underway), Seamoon Industrial Park

## Climate

- Tropical: wet season May–Nov, dry season Dec–Apr
- Hurricane season: official June–Nov, peak Aug–Oct
- Average rainfall: ~2,000mm/year
- Temperature: 24–30°C year-round
